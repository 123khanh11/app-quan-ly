## ⚠️ Potential Issues

### Issue 1: variant_id có thể là empty string
**Code:** `variant_id: item.variant_id || ''`

```
Database: variant_id uuid NOT NULL
Code gửi: '' (empty string)
❌ Type mismatch: expecting UUID, got empty string
```

**Fix:**
```typescript
// Nên kiểm tra variant_id
if (!item.variant_id) {
  console.warn('⚠️ Skipping item: missing variant_id')
  continue  // Skip item without variant_id
}

// Hoặc gửi valid UUID
variant_id: item.variant_id,  // Không dùng || ''
```

### Issue 2: Dimensions có thể undefined
**Code:** 
```typescript
weight_kg: item.weight ? item.weight / 1000 : undefined,
length_cm: item.length,
width_cm: item.width,
height_cm: item.height,
```

**Database:** `numeric NULL` ✅ (cho phép NULL)

**Status:** ✅ OK - vì columns là nullable

## 🔧 Recommended Fix

Update CheckoutForm.tsx để validate variant_id:

```typescript
const orderItems = cartItems
  .filter((item) => {
    const itemKey = `${item.product_id}-${item.color}-${item.size}`
    if (!selectedItems.has(itemKey)) return false
    
    // ✅ Check variant_id exists
    if (!item.variant_id) {
      console.warn('⚠️ Skipping item without variant_id:', item.name)
      return false
    }
    
    return true
  })
  .map((item) => ({
    product_id: item.product_id,
    variant_id: item.variant_id,    // ✅ No fallback to ''
    product_name: item.name,
    // ... rest
  }))
```

This ensures only items with valid variant_id are sent to database.
