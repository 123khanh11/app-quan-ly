## 📤 Bạn Cần Làm Điều Này

### Step 1: Tạo GitHub Repository

**Vào:** https://github.com/new

**Điền:**
- Name: `ecommerce-shop`
- Description: `E-commerce Shop`
- Select: **Public**
- Click: **Create repository**

**Nhận được URL như:**
```
https://github.com/YOUR_USERNAME/ecommerce-shop.git
```

---

### Step 2: Push Lên GitHub

Chạy 3 lệnh này (thay YOUR_REPO_URL):

```bash
git remote add origin YOUR_REPO_URL
git branch -M main
git push -u origin main
```

**Ví dụ:**
```bash
git remote add origin https://github.com/yourname/ecommerce-shop.git
git branch -M main
git push -u origin main
```

✅ **Xong!** Code đã lên GitHub

---

### Step 3: Deploy Vercel

**Vào:** https://vercel.com/new

**Chọn:**
1. Click **Import Git Repository**
2. Chọn: `ecommerce-shop`
3. Click **Import**
4. Leave defaults
5. Click **Deploy**

**Chờ 1-2 phút...**

✅ **Xong!** Website sống rồi!
