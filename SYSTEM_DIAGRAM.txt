================================================================================
                            DATA FLOW SEQUENCE
================================================================================

1. LOAD PROVINCES
   ┌─ Frontend: "Tính Phí"
   │  └─ getProvinces()
   │     └─ GET /api/ghn/province
   │        └─ Backend: fetch GHN API
   │           └─ GHN: Return list of 63 provinces
   │              └─ Backend: Return to frontend
   │                 └─ Frontend: Display dropdown

2. SELECT PROVINCE & LOAD DISTRICTS
   ┌─ User: Select "Hà Nội"
   │  └─ useEffect triggers
   │     └─ getDistricts(1)
   │        └─ GET /api/ghn/district?province_id=1
   │           └─ Backend: fetch GHN API
   │              └─ GHN: Return districts of Hà Nội
   │                 └─ Backend: Return to frontend
   │                    └─ Frontend: Display new dropdown

3. SELECT DISTRICT & LOAD WARDS
   ┌─ User: Select "Hà Đông"
   │  └─ useEffect triggers
   │     └─ getWards(1455)
   │        └─ GET /api/ghn/ward?district_id=1455
   │           └─ Backend: fetch GHN API
   │              └─ GHN: Return wards of Hà Đông
   │                 └─ Backend: Return to frontend
   │                    └─ Frontend: Display new dropdown

4. SELECT WARD & CALCULATE FEE
   ┌─ User: Select "Bến Nghé"
   │  └─ useEffect triggers
   │     └─ calculateShippingFee({
   │          service_id: 2,
   │          from_district_id: 1455,      # Kho (Hà Đông)
   │          from_ward_code: "21617",     # Kho (Dương Nội)
   │          to_district_id: 1542,        # Customer (Quận 1)
   │          to_ward_code: "30711",       # Customer (Bến Nghé)
   │          weight: 1000,                # 1kg
   │          length: 20, width: 20, height: 20
   │        })
   │        └─ POST /api/ghn/fee
   │           └─ Backend: fetch GHN API with Token
   │              └─ GHN: Calculate and return fee: 36300 VNĐ
   │                 └─ Backend: Return to frontend
   │                    └─ Frontend: Display: "36.300 VNĐ"

5. DISPLAY TOTAL
   ┌─ Summary Box:
   │  ├─ Tiền hàng:      250.000 VNĐ
   │  ├─ Phí vận chuyển: 36.300 VNĐ
   │  └─ Tổng cộng:      286.300 VNĐ

6. SUBMIT ORDER
   ┌─ User: Click "Đặt Hàng"
   │  └─ Create order in Supabase
   │     └─ Order saved with shipping fee: 36300
   │        └─ Display: "Đặt hàng thành công!"

================================================================================
                        API REQUEST/RESPONSE
================================================================================

REQUEST (Frontend):
POST http://localhost:5000/api/ghn/fee
Headers:
  Content-Type: application/json

Body:
{
  "service_id": 2,
  "from_district_id": 1455,
  "from_ward_code": "21617",
  "to_district_id": 1542,
  "to_ward_code": "30711",
  "weight": 1000,
  "length": 20,
  "width": 20,
  "height": 20,
  "insurance_value": 0,
  "coupon": null
}

BACKEND PROCESSING:
1. Receive parameters
2. Load GHN_TOKEN from process.env
3. Call GHN API with Token header
4. Process response

RESPONSE (GHN API):
{
  "code": 200,
  "message": "Success",
  "data": {
    "total": 36300,
    "service_fee": 36300,
    "insurance_fee": 0,
    "pick_station_fee": 0,
    "coupon_value": 0,
    "r2s_fee": 0,
    "document_return": 0,
    "double_check": 0,
    "cod_fee": 0,
    "pick_remote_areas_fee": 0,
    "deliver_remote_areas_fee": 0,
    "cod_failed_fee": 0
  }
}

BACKEND RETURNS TO FRONTEND:
{
  "success": true,
  "data": {
    "total": 36300,
    "service_fee": 36300,
    ...
  }
}

FRONTEND DISPLAYS:
"Phí vận chuyển: 36.300 VNĐ"
