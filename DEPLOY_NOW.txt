🎯 GOAL: Deploy frontend to Vercel in 5 minutes

================================================================================
                             STEP 1: GITHUB
================================================================================

1. Create GitHub Account
   → https://github.com/signup

2. Create New Repository
   → https://github.com/new
   → Name: e-commerce-website-interface
   → Visibility: Public
   → Click "Create repository"

3. Copy the commands from GitHub (after creating repo)

================================================================================
                           STEP 2: LOCAL SETUP
================================================================================

Open Terminal and run:

# 1. Ensure everything is committed
cd "c:\Users\baomu\Downloads\E-commerce website interface"
git status

# 2. If there are changes, commit them
git add .
git commit -m "Ready for Vercel deployment"

# 3. Add GitHub as remote (paste from GitHub)
# Example:
git remote add origin https://github.com/YOUR_USERNAME/e-commerce-website-interface.git

# 4. Change branch to main
git branch -M main

# 5. Push to GitHub
git push -u origin main

Wait for upload to complete...

================================================================================
                            STEP 3: VERCEL
================================================================================

1. Sign Up / Login
   → https://vercel.com
   → "Continue with GitHub"
   → Authorize Vercel

2. Import Project
   → Click "New Project"
   → Select "e-commerce-website-interface"
   → Click "Import"

3. Configure
   → Framework: Vite
   → Root Directory: ./
   → Build Command: npm run build
   → Output Directory: dist
   → Leave everything else default

4. Environment Variables (OPTIONAL)
   → For now, leave empty
   → We'll add backend URL later

5. Deploy
   → Click "Deploy"
   → WAIT 2-3 MINUTES...
   → You'll see: "Congratulations! Your project has been deployed"

================================================================================
                         RESULT: FRONTEND LIVE!
================================================================================

Your URL: https://your-project-name.vercel.app

✅ Frontend deployed!
⏳ Now need to deploy backend...

================================================================================
                           STEP 4: BACKEND (Railway)
================================================================================

1. Create Railway Account
   → https://railway.app
   → Sign up
   → Connect GitHub

2. Create New Project
   → Click "New Project"
   → "Deploy from GitHub repo"
   → Select "e-commerce-website-interface"
   → Create

3. Add Environment Variables
   → Click "Variables"
   → Add:
     GHN_TOKEN=653bfc7b-8381-11f1-a65e-a68e06d4dd1e
     GHN_SHOP_ID=5430969
     GHN_API_URL=https://dev-online-gateway.ghn.vn/shiip/public-api/v2
     GHN_FROM_DISTRICT_ID=1455
     GHN_FROM_WARD_CODE=21617

4. Deploy
   → Click "Deploy"
   → WAIT 1-2 MINUTES...
   → You'll see: "Deployment successful"

5. Get Backend URL
   → Go to Settings
   → Domain
   → Copy: https://your-backend-*.railway.app

================================================================================
                         RESULT: BACKEND LIVE!
================================================================================

Your Backend URL: https://your-backend-*.railway.app

✅ Backend deployed!

================================================================================
                      STEP 5: CONNECT FRONTEND → BACKEND
================================================================================

1. Go back to Vercel Dashboard
   → Select your project
   → Settings
   → Environment Variables

2. Add:
   VITE_API_URL=https://your-backend-*.railway.app

3. Redeploy
   → Go to Deployments
   → Click the latest deployment
   → Click "Redeploy"
   → WAIT 1-2 MINUTES...
